🐍 Solana Snake

Retro Snake. On-chain ready. Built for Solana Mobile.

Classic Nokia-style Snake game built with Expo + React Native for Android. Connect your Solana wallet, eat food, grow your snake, and chase the high score.

View on GitHub Download APK

Features

🎮

Classic Gameplay

20×20 grid, retro LCD color palette, D-pad controls and swipe gestures.

⚡

3 Difficulty Levels

Easy, Normal, and Hard — from 200ms to 90ms per tick.

👛

Solana Wallet

Connect any MWA-compatible wallet (Phantom, Solflare) via Mobile Wallet Adapter.

🏆

High Score

Local high score persistence. On-chain leaderboard coming soon.

📱

Android Native

Built with Expo SDK 52 + React Native 0.76 for smooth Android performance.

🔓

Open Source

Fully open source on GitHub. MIT licensed.

Built With

Expo SDK 52 React Native 0.76 Mobile Wallet Adapter v2 @solana/web3.js Expo Router v4 EAS Build TypeScript
